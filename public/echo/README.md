# Echo source media

The Echo Lab expects original, appropriately licensed echo loops at these paths:

- public/echo/plax.mp4
- public/echo/psax.mp4
- public/echo/a4c.mp4
- public/echo/a2c.mp4

These media assets are not included in this repository. The application deliberately displays a missing-asset error rather than generating or drawing ultrasound frames. Add the real files here and redeploy to enable playback.
