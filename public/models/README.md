# Heart model asset

The planned 3D scan-plane view expects a real, appropriately licensed model at:

- public/models/heart.glb

The GLB must be derived from or aligned to the same CT source used for public/volumes/heart_acoustic.bin. Record its coordinate transform and source/segmentation provenance. Do not create a procedural heart mesh or use the CT preview sample in a public deployment until its redistribution terms are verified.
